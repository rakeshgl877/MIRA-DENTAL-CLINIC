# Mira Dental Clinic — Premium Concept Website
### Designed & Developed by Mavern Studio for Mira Dental Care & Implant Centre, Bengaluru

A luxury, editorial-grade web application created for **Mira Dental Care & Implant Centre**, located on Hesarghatta Main Road, Bagalagunte, Bengaluru. Designed to elevate the clinic's digital presence, instill trust, and maximize patient appointment conversions via WhatsApp.

---

## 💎 Visual Direction & Design System

- **Warm Ivory (`#F7F4EC`)**: Elegant, warm medical canvas avoiding cold clinical aesthetics
- **Deep Forest Green (`#183D32`)**: Grounded, authoritative luxury medical branding
- **Champagne Gold (`#C6A875`)**: Refined editorial accents, trust markers, badges & borders
- **Charcoal (`#252B26`)**: High-contrast, crystal-clear typography
- **Typography**:
  - Headings: `Cormorant Garamond` (Sophisticated serif)
  - Body & UI: `Manrope` (Clean, geometric readability)

## ⚡ Key Features & Sections

1. **Sticky Luxury Navbar:** Responsive brand header with live consultation timings, phone dialer, navigation links, and desktop/mobile CTAs.
2. **Hero Viewport:**
   - Headline: *"Where exceptional care meets confident smiles."*
   - Supporting narrative, 4.8★ Google Trust Pill, Gold Medalist Endodontist badge, and primary/secondary CTAs.
3. **Trust Section:**
   - 4.8 Rating highlight, 238+ reviews, MEI Layout landmark verification, and 4 clinical pillars (Painless Tech, Class-B Autoclave, Gold Medal Leadership, Ethical Care).
4. **Treatment Showcase:**
   - 6 Core Treatments: *Dental Implants*, *Root Canal Treatment (RCT)*, *Invisalign & Clear Aligners*, *Braces & Orthodontics*, *Smile Designing & Veneers*, *General & Preventive Dentistry*.
   - Each card features curated photography, treatment duration, candidate profile, and a direct "Enquire on WhatsApp" action with custom message strings.
5. **Editorial About Section:**
   - Philosophy of conservative dentistry, hospital-grade Class-B vacuum sterilization, and digital RVG diagnostics with 90% reduced radiation.
6. **Meet the Doctors:**
   - Detailed profile of Dr. Ashwini Marurkar (MDS Gold Medalist) with registration details and clinical philosophy, alongside the associate multi-specialty team.
7. **Patient Testimonials:**
   - Authentic patient reviews citing painless root canals, hygiene, and gentle dental care with reviewer names and Google verification badges.
8. **Interactive Clinic Gallery:**
   - 6 facility spaces (Reception, Treatment Suite, RVG Diagnostic Room, Sterilization Area, Consultation Office, Patient Recovery Lounge) with category filtering and an accessible full-screen Lightbox with keyboard navigation.
9. **Patient FAQ:**
   - 8 comprehensive answers addressing appointment booking, pain-free rotary RCT, clear aligners, timings, and emergency assistance.
10. **Location & Contact:**
    - Embedded Google Maps interactive frame, landmark directions opposite MEI Ground, working hours, and one-click WhatsApp/Call actions.
11. **Omnipresent WhatsApp Conversion System:**
    - Navbar CTA
    - Hero CTA
    - Treatment-specific message triggers
    - Floating concierge WhatsApp widget with quick topic selection
    - Mobile sticky booking bar
    - Interactive appointment scheduling modal generating an instant WhatsApp booking payload.
12. **Full SEO & Schema.org LocalBusiness Markup:**
    - Structured JSON-LD Dentist data, Open Graph meta tags, Twitter cards, and semantic HTML5 hierarchy.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS (Custom extended luxury palette)
- **Animations:** Framer Motion
- **Icons:** Lucide React

## 🚀 How to Run Locally

```bash
# Navigate to the project folder
cd mira-dental-website

# Install dependencies (if needed)
npm install

# Start the local development server
npm run dev

# Or build and test production bundle
npm run build
npm run preview
```
